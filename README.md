# Free News Web Application

A modern Node.js web application that provides real-time news data without requiring any API signups.

## ✨ Features

- **No API Signup Required**: Uses free Open-Meteo API
- **JWT Authentication**: Secure token-based authentication
- **Modern ES6 Syntax**: Uses import/export modules
- **Axios HTTP Client**: For both frontend and backend
- **Responsive Design**: Mobile-friendly interface
- **Error Handling**: Comprehensive error management
- **Real-time Logging**: Winston logger with file transport

## 🚀 Quick Start

1. **Install dependencies**
   ```bash
   npm install
   ```
